### [Lending Club Loan Default Prediction](https://github.com/Zeye430/Lending-Club-Loan-Default-Predict)

Originally developed as a graduate team project. My contributions focused on data cleaning, chronological train/validation/test splitting, preprocessing, model implementations, and model selection. I'm continuing the project as an independent extension with a focus on explainability and production-oriented engineering.
